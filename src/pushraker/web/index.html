WebhookGuide
For Home Assistant, Node-RED, n8n or your own scripts. It gets every notification, whatever the Push and Email columns say.
Each notification is POSTed as JSON: title, message, type (info, success, warning, failure), event (e.g. complete; use it to pick), printer, the links, and the image in attachments (base64).
